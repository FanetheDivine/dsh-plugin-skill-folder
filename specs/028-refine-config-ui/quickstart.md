# Quickstart: 优化配置页视觉与批量浏览交互

## 前置条件

- Node.js ≥ 24.9
- pnpm 11

## 验证命令

```sh
pnpm format
pnpm check
pnpm build
```

## 验证场景

1. **空文件夹状态**：
   - 当 `folders` 为 `[]` 时，配置页「文件夹」区域渲染 `data-folders-empty` 空状态引导文案，且不显示批量折叠按钮。
2. **批量折叠与展开**：
   - 当存在多个文件夹且至少一个展开时，分区标题行渲染「全部折叠」按钮；点击后全部文件夹折叠，按钮切换为「全部展开」。
   - 当全部文件夹已折叠时，点击「全部展开」恢复展开全部文件夹。
3. **图标与交互样式**：
   - 新建文件夹、按前缀自动分组、筛选框、折叠箭头、删除按钮与技能拖拽手柄均渲染对应的宿主矢量图标（`data-icon`）。
   - 样式表包含 `:focus-visible`、`:focus-within` 与 `:hover` 交互高亮规则。
4. **双语一致性**：
   - `zh` 与 `en` 键集一致，中英文渲染均包含新增文案。
