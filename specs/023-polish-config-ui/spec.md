## User Scenarios & Testing *(mandatory)*

### User Story 1 - 快速浏览并整理技能 (Priority: P1)

用户打开插件配置页，通过清晰的标题、操作区、文件夹卡片和未分组区域了解当前配置，并完成新建、编辑、拖拽或移动技能。

**Why this priority**: 配置分组是页面的主要任务，清晰的层级与一致的操作能降低理解成本。

**Independent Test**: 打开包含多个文件夹与未分组技能的配置页，检查各区域的视觉层级并完成一次技能移动。

**Acceptance Scenarios**:

1. **Given** 配置已加载，**When** 用户浏览页面，**Then** 页面标题、主要操作、文件夹、未分组技能与搜索选项具有明确且一致的层级。
2. **Given** 配置可编辑，**When** 用户新建文件夹或移动技能，**Then** 现有编辑、拖拽、下拉移动和保存流程保持可用。

---

### User Story 2 - 在长列表中定位技能 (Priority: P2)

用户面对较多文件夹和技能时，使用统一筛选与文件夹折叠快速找到目标，并控制页面展示的密度。

**Why this priority**: 技能数量增长后，浏览与定位效率直接影响分组效率。

**Independent Test**: 构造跨多个文件夹的匹配项，执行筛选、清除筛选与折叠操作，检查结果和计数。

**Acceptance Scenarios**:

1. **Given** 多个文件夹和未分组区域都有技能，**When** 用户输入名称或描述关键词，**Then** 所有区域只展示匹配成员。
2. **Given** 筛选没有匹配项，**When** 用户查看页面，**Then** 各空区域给出与筛选状态一致的提示，且可清除筛选。
3. **Given** 文件夹包含成员，**When** 用户折叠或展开文件夹，**Then** 成员列表相应隐藏或显示，名称、简介与成员计数保持可见。

---

### User Story 3 - 理解状态并完成键盘操作 (Priority: P3)

用户通过状态提示了解加载、错误、筛选和配置校验结果，并使用键盘访问主要控件。

**Why this priority**: 一致的状态反馈与可访问名称能减少误操作并覆盖非鼠标操作。

**Independent Test**: 分别渲染加载、错误、空结果和只读状态，并通过可访问名称定位主要控件。

**Acceptance Scenarios**:

1. **Given** 页面处于加载、错误或配置错误状态，**When** 用户查看提示，**Then** 状态信息与对应操作保持清晰且互不混淆。
2. **Given** 用户使用键盘，**When** 焦点经过筛选、折叠、编辑、移动与保存控件，**Then** 每个控件都有可识别名称和可见的交互状态。

### Edge Cases

- 筛选期间折叠状态保持独立，清除筛选后恢复显示该文件夹的全部成员。
- 空文件夹折叠后仍保留名称、简介和计数，放置区保持可用。
- 技能列表加载失败时保留现有配置，并继续提供重试。
- 窄屏下工具栏、卡片与控件折行，长名称保持可读且不撑破布局。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 配置页 MUST 提供清晰的页面标题、用途说明和分组操作区。
- **FR-002**: 文件夹与未分组区域 MUST 使用一致的视觉层级，并在窄屏下自适应排列。
- **FR-003**: 筛选 MUST 同时作用于已分组与未分组技能，匹配名称或描述。
- **FR-004**: 用户 MUST 能清除筛选，并看到当前筛选结果数量。
- **FR-005**: 每个文件夹 MUST 支持独立折叠和展开成员列表。
- **FR-006**: 文件夹折叠时 MUST 保留名称、简介、成员计数、删除和放置能力。
- **FR-007**: 加载、错误、不完整列表、校验错误与空结果 MUST 保持可区分的状态反馈。
- **FR-008**: 现有新建、改名、简介编辑、删除、拖拽、下拉移动、自动分组、保存与放弃流程 MUST 保持可用。
- **FR-009**: 所有新增用户可见文案 MUST 提供中英文版本。
- **FR-010**: 新增交互控件 MUST 具有可访问名称，并保持键盘可用。

### Key Entities *(include if feature involves data)*

- **文件夹视图**：展示名称、简介、成员计数、展开状态与筛选后的成员。
- **筛选状态**：包含关键词、匹配结果数量与清除动作，不修改已保存配置。
- **技能条目**：展示名称、归属与移动操作，缺失成员保持现有警示。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可在一次筛选中定位任意文件夹或未分组区域内的匹配技能，覆盖率达到全部可见技能。
- **SC-002**: 用户可用一次操作折叠任一有成员的文件夹，折叠后成员列表从布局中隐藏且计数仍可见。
- **SC-003**: 页面在 320 像素及以上可用宽度下无横向溢出，主要操作无需横向滚动。
- **SC-004**: 全部现有配置流程的自动化测试通过，新增筛选、折叠和中英文案具有行为测试。
- **SC-005**: 主要交互控件均可通过可访问名称定位，键盘可完成筛选、折叠、移动与保存。

## Assumptions

- 优化范围限于插件行配置页，宿主整体导航与插件页布局保持不变。
- 沿用宿主主题、表单运行时与现有配置模型。
- 折叠和筛选是临时视图状态，不写入插件配置。
- 本次优化不调整技能检索、目录折叠与配置数据结构。
