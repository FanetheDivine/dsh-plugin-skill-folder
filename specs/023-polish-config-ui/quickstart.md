# Quickstart: 验证配置 UI 优化

## 前置条件

- Node.js 24.9 及以上。
- pnpm 11。
- 已安装仓库依赖与 Playwright Chrome。

## 自动化检查

```sh
pnpm format
pnpm check
pnpm build
```

预期：类型检查、Biome、源码测试、构建与产物测试全部通过。

## 行为场景

1. 打开含至少两个文件夹和未分组技能的配置页。
2. 输入只匹配已分组技能描述的关键词。
3. 预期：目标文件夹保留匹配成员，其他区域显示筛选空状态，结果计数准确。
4. 清除筛选。
5. 预期：全部成员恢复显示，折叠状态保持不变。
6. 折叠一个有成员的文件夹。
7. 预期：名称、简介、计数和删除按钮可见，成员列表隐藏，卡片仍能接收拖放。
8. 删除位于折叠文件夹之前的另一个文件夹。
9. 预期：折叠状态仍属于原文件夹。
10. 切换中英文。
11. 预期：新增标题、筛选、计数和折叠文案均随语言切换。

## 响应式检查

- 在桌面宽度与 320px 宽度分别打开配置页。
- 预期：页面无横向溢出，控件可用，卡片按可用宽度排列。
- 检查加载、读取失败、不完整列表、配置错误和只读状态。
- 预期：状态文案与操作保持清晰，现有保存和重试流程可用。
