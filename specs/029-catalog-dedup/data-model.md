# Data Model: 折叠目录重复注入修复

**Feature**: `fix/029-catalog-dedup` | **Date**: 2026-11-26

本次不引入持久化模型。下面三个概念都是单步内的内存值，生命周期不超过一次 `agent/pre-step`。

## 折叠正文（FoldedBody）

一份目录在模型面前实际呈现的内容，不含首句。

| 组成 | 来源 | 说明 |
| --- | --- | --- |
| 未折叠条目行 | 本轮目录消息的 `entries` 与本轮技能快照 | 顺序沿用原生条目顺序，格式 `- \`<name>\`: <description>` |
| 文件夹摘要行 | 生效的文件夹配置 + 本轮技能快照 | 按配置顺序，只列至少有一个成员被折叠的文件夹 |
| 固定加载指引 | 常量文本 | 与现状逐字节相同 |

**约束**：

- 首句（首次发布或更新的措辞）不属于正文。
- 正文由渲染函数一次算出，比较与输出共用同一份结果，避免两处拼接不一致。
- 技能名与描述来自宿主，转义规则不变。

## 已呈现记录（PresentedBody）

本会话当前对模型可见的记录里，最后一份目录消息的正文。

| 属性 | 取值 |
| --- | --- |
| 来源 | `agent.session.deriveMessages()` 结果中从后向前第一条 `role === 'user'` 且 `source.kind === 'skill-catalog'` 的消息 |
| 内容 | 该消息首个文本块里从 `<available_skills>` 起的部分 |
| 缺失情形 | `deriveMessages` 不存在、抛错、没有目录消息、文本块结构异常 → 记为未知 |

**状态转换**：

```text
无目录 → 宿主发布首份目录 → 注入（正文写入会话）
已呈现 A → 宿主重发正文 A → 丢弃（会话不变，仍是 A）
已呈现 A → 宿主发布正文 B → 注入 B（会话里 A、B 都在，A 不清理）
已呈现 A → 上下文压缩移出 A → 下一次发布 → 按「无目录」注入
```

## 判定结果（DedupDecision）

| 取值 | 条件 | 动作 |
| --- | --- | --- |
| `same` | 本轮正文 === 已呈现正文 | 从本步骤消息列表过滤掉这条目录消息 |
| `different` | 已呈现正文存在且不相等 | 注入折叠后的目录消息 |
| `unknown` | 已呈现正文不可得 | 注入折叠后的目录消息，并记一条 warn |

## 折叠上下文（FoldContext，扩展）

现有字段 `skills`、`folders`、`toolVisible` 不变，新增：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `presented` | `string \| undefined` | 已呈现正文；`undefined` 表示未知 |

## 不变式

- 折叠文本与现状逐字节相同。
- 没有条目被折叠时返回原消息对象，判断不介入。
- `source.entries` 保持宿主原值。
- 被丢弃的目录消息不写会话记录。
- 判定失败不影响该步骤的其余消息。
