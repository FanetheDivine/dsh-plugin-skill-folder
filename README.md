# dsh-plugin-skill-folder

DSH 插件：把全局技能归入文件夹，模型目录只显示文件夹的名称、简介与成员数。折叠的成员仍可通过 `skill_search` 找到，再用原生 `skill` 加载完整指令。

## 功能

- 技能文件夹：模型目录用文件夹摘要替代已折叠成员的条目，未归组的技能继续逐项展示。
- `skill_search`：按关键词或文件夹名检索可由模型调用的技能，返回摘要、所属文件夹与检索完整性。
- 可视化分组：在“插件”页的本插件行里拖拽分组，或用「移动到」下拉框操作。
- 按前缀自动分组：先按文件夹名匹配，其余未分组技能按 `-` 分段前缀合并。
- 只读取技能摘要，不读取指令正文；只折叠全局技能，项目级技能照常逐项展示。
- 插件标题与描述随宿主语言切换，中英文各一份。

## 安装

先停用其他提供 `skill_search` 的插件，例如 `dsh-skill-search-local`。两个插件同时启用时，先注册的一方保留工具名。

```sh
dsh plugin add <包名或本地目录>
```

停用旧插件：

```sh
dsh plugin disable skill-search-local
dsh plugin add dsh-plugin-skill-folder
```

## 配置

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `folders` | `[]` | 文件夹列表，见下方结构 |
| `defaultLimit` | `5` | 模型未指定数量时的返回条数，1–20 |
| `descriptionMaxLength` | `320` | 摘要字符上限，40–2000 |

文件夹结构：

```yaml
folders:
  - name: lark
    description: 飞书工具
    skills:
      - lark-calendar
      - lark-docs
```

| 字段 | 规则 |
| --- | --- |
| `name` | 去首尾空白后 1–64 字符，忽略大小写唯一 |
| `description` | 0–500 字符，可为空；为空时目录只显示名称与成员数 |
| `skills` | 技能名列表，同一技能最多属于一个文件夹 |

三个字段都是 `volatile`：保存后新配置立即用于后续模型目录与检索，已有会话保持其原有目录。

在“插件”页打开本插件的行详情即可编辑。改动先进入草稿，点「保存」才写入；「放弃修改」恢复生效配置。

## 分组

- **拖拽**：把技能条目拖到目标文件夹卡片，或拖到「未分组的技能」区域移出文件夹。
- **下拉框**：每个技能条目右侧的「移动到」可完成同样的操作，键盘可用。
- **筛选**：按名称或描述同时筛选文件夹内与未分组的技能，结果计数显示匹配数量，可一键清除。
- **折叠**：文件夹标题左侧的箭头可隐藏或展开成员列表，名称、简介、计数与拖放目标保持可用。
- **新建与删除**：删除文件夹后其成员回到未分组区域。
- **按前缀自动分组**：只处理未分组技能。
  1. 名称等于某文件夹名称，或以「文件夹名称-」开头的技能进入该文件夹；匹配多个文件夹时进入名称最长的那个。
  2. 其余技能按第一个 `-` 之前的名称分桶，成员不足 2 个的桶保持未分组。
  3. 新文件夹名称取成员按 `-` 分段的最长公共前缀。`lark-doc-a`、`lark-doc-b`、`lark-sheet`、`lark-calendar` 合并为 `lark`；只有 `lark-doc-a`、`lark-doc-b` 时为 `lark-doc`。
  4. 与已有文件夹重名时并入该文件夹。

## 工具

| 工具 | 参数 | 返回 |
| --- | --- | --- |
| `skill_search` | `query` 或 `folder`，可选 `limit`、`offset` | 摘要、所属文件夹、匹配类型、总数、分页与完整性 |

- `query`：能力关键词或准确技能名，最多 512 字符，中英文均可。
- `folder`：文件夹名，列出该文件夹全部可用成员，忽略大小写。
- `limit`：1–20，缺省用 `defaultLimit`。
- `offset`：跳过多少条，缺省 0。
- `match`：`exact` 为准确名称或命中全部查询词，`partial` 为命中部分查询词，`folder` 为按文件夹列出。

检索只包含可由模型调用的技能。结果为空时说明技能不存在或当前检索不完整。

## 与其他技能插件的关系

- 本插件不修改其他插件的启用状态。
- 原生 `skill` 工具、用户 `/技能名` 调用与原生目录元数据保持一致，折叠只改变模型看到的列表。
